# 渐进 Refiner 使用说明（v2.3.0）

渐进 Refiner 帮你把一句模糊的想法，一步步变成可以直接用的成果：先让 AI 大胆铺开整体，再一步步收紧，只改你选中的地方。你亲手改过的内容会被保护，AI 不会再动。

> 默认是**简单模式**，界面只保留完成任务需要的东西。想看智能体分工、自由度、流水线等细节时，打开右上角的「专家模式」开关。截图在交付目录的 `截图/` 文件夹（文件名以窗口尺寸开头，如 `1280x800-05-…`），下文用【图 xx】标注。
>
> **v1.6 新增**：从已有材料开始（Word/PDF/Excel/XMind…）、参考资料、单击即可编辑和拖拽排序、进入下一步不再自动运行、运行中实时显示生成内容、并排对比任意两版、tokens 与费用、预算上限、自动备份与恢复、API Key 加密、检查更新、界面缩放。

## 1. 第一次打开：先用演示模式体验
- 不需要任何 API Key。右上角黄色徽标「演示模式 · 去配置」表示当前用的是内置示例，不调用真实 AI。【图 01】
- 首页点「试试」里的例子（团建、小程序数据库、秋天的歌）可以看到完整的演示样例，顶部会提示「演示样例」。【图 06、07】

## 2. 界面只有两块：内容 + 底部操作栏
- **上面是内容**：顶部一条步骤条是唯一的“我在第几步”（已完成的步骤可以点击“回到这一步”，跳过的显示“—”）。步骤条下一行写着“这一步：……”。
- **下面是固定的操作栏**：左边永远写明 **AI 将修改哪里**（“将修改：全部”或“将修改：「第 2 天」（含 3 项）”），中间可以选怎么改、写补充要求，右边是**唯一的蓝色主按钮**——每个屏幕都在同一个位置。
- 左侧栏列出你的作品，后面的 `2/4` 是进度；窗口较窄（< 1200 像素）时左侧栏自动收成图标条。【图 07、窄窗口图】

## 3. 做一件事的完整流程（4 步约 9 次点击）
1. **说出想法**：首页输入一句话，点「开始 →」（或 Ctrl+Enter），也可以直接点「试试」里的例子。【图 01】
2. **回答几个小问题（可跳过）**：想法太短或太含糊（如“帮我弄一下”）时，会先问 3 个问题。点按钮选择（选中的会打勾），或在“其他”里自己写；下面会显示“将按这个来规划：……”。点「继续」或「跳过」。【图 02】
3. **确认步骤**：AI 建议分几步完成，左边的色条表示从“AI 放得开”到“AI 很克制”。步骤名称和说明都能直接改，也能加一步、删一步。名称、放入哪个项目等收在「更多设置」里。点底部「开始第 1 步 →」。【图 03】
4. **运行中**：底部操作栏显示“AI 正在：检查（第 3/5 步，已用 8 秒）”，按 **Esc** 或「停止」随时取消，内容保持原样。【图 04】
4b. **运行中能看到内容在长出来**：点开始后内容区立即出现灰色占位行；模型一边写，已经写好的部分一边显示出来（“正在生成… 已出 3 个部分”）。【图 37a、37】
5. **看结果、进入下一步**：完成后操作栏左边显示“AI 新增 3 处、修改 1 处（检查得分 6.5 → 9）”，并**自动滚动到第一处改动**。主按钮是「全部保留，进入下一步：X →」——点一次就保留改动、进入下一步，然后**停下来等你**：操作栏显示「将修改：全部 ▾」，点它可以改成“只改「某一部分」”（也可以直接在内容里点选），再点主按钮开始。想要以前那样自动开始，在「设置 → 使用习惯」打开“进入下一步时自动开始”。【图 05、38】
6. **只改一部分**：点选内容里的任意一项，右侧浮出编辑面板，操作栏变为“将修改：「X」”，主按钮变为“补充细节「X」→”。点 ✕ 或点空白处取消选中。切换步骤时选中会自动清除。【图 08】
7. **完成**：最后一步点「完成」，出现完成卡：导出为 Word / 复制到剪贴板 / 其他格式，以及“继续修改 · 存为模板 · 新建”。【图 09】

## 3b. 从已有材料开始【图 31、32、32b、32c】
已经有一份草稿？首页输入框下方点「选择文件」，或直接把文件拖到那一栏：
- **文档**：Word（.docx）、PDF（有文字层的）、Markdown / 文本、Excel（.xlsx）/ CSV。原文会作为**参考资料**挂在作品上；同时按标题层级、列表或表格行识别出结构，可选“把识别出的结构作为初稿”。
- **结构**：XMind（.xmind）、OPML、JSON / YAML（包括本应用导出的文件，可以来回导入导出）。
- 确认步骤页会说明“已读取「团建方案.docx」· 识别出 3 个部分、10 项”，以及**从第几步接着做**（按内容的细化程度自动判断，例如“已有 2 层、10 项，从「日程骨架」接着做”）。点「打开初稿，从第 2 步…接着做」即可。不勾选“作为初稿”则从第 1 步重新生成，只把原文当参考。
- 全部在本机解析，不联网，Windows 上离线可用。扫描版 PDF 没有文字层，会提示只能作空白参考。

## 3c. 参考资料【图 33】
工具栏「资料」打开参考资料面板：可以添加文件、粘贴文字、填网址（会尝试读取网页文字；读不到就只记下网址，你可以把正文粘贴进来）。
- 之后**每一步**都会把这些资料发给 AI，要求优先采用其中的事实和约束。
- 总量上限 12,000 字（避免提示词过长、费用失控）；超出部分不发送，面板里会写明“只发送前 N 字（已截断）”。每份资料都可以临时“停用”。

## 3d. 直接编辑【图 34、35、36、36b】
- **单击标题**直接改字；**Enter** 在下面新建同级，**Tab** 缩进成上一项的子项，**Shift+Tab** 提升一级，空行按 **Backspace** 删除，**Esc** 结束编辑。像大纲笔记软件一样连续录入。
- 选中一项后：**F2** 或 **Enter** 编辑标题，**Delete** 删除，**Tab / Shift+Tab** 调整层级。
- **拖拽**：鼠标移到一行左侧出现 ⠿ 把手，拖动即可排序；拖到某一项的**上沿/下沿**是放在它前/后（蓝线），拖到**中间**是变成它的子项（虚线框）。看板里把卡片拖到另一列即改状态；表格里拖动行首的把手调整顺序。
- 每次移动、删除都会提示“已移动「X」到「Y」前 · 撤销”；Ctrl+Z 的提示会写明撤销了什么（如“已撤销：删除「风险与预案」”）。
- 键盘焦点有清晰的蓝色焦点框。**Esc** 依次关闭：弹出的菜单 → 底部面板（AI 过程 / 历史 / 资料）→ 取消选中。

## 4. 审阅 AI 的改动
- 改动处带「新」「改」标记，悬停可看改前内容；每一处都能单独 ✓ 保留或 ↶ 撤销。
- 操作栏里的 ‹ 1/4 › 在改动之间跳转（快捷键 J / K）；「为什么这样改？」显示 AI 检查时发现的问题。
- 「再来一次 ▾」里有：再来一次、只保留并留在这一步、全部撤销、跳过这一步。
- 随时 Ctrl+Z 撤销（会提示“已撤销：……”，可点「重做」）。「历史」按钮列出所有版本，每个版本显示**结构化的改动清单**（新增 / 修改 / 删除，改动处有字级差异，属性显示为“负责人：王敏”，不再是机器格式）。
- **并排对比**【图 39、39b、40】：「再来一次」之后，菜单里有「与上一版并排对比」；历史里可「与上一版对比」，或勾选任意两个版本「并排对比所选 2 版」。左右两栏按部分对齐，新增绿、删除红、改动黄，改动项内显示具体改了哪几个字。每个部分都有「用这一版」，也可以「整版用这一版」。两边的版本都可以在顶部下拉里换。
- 你亲手改过的内容会被保护（图钉标记），之后 AI 不会覆盖。

## 5. 接入真实模型
1. 点右上角「去配置」或左下「设置与模型」。
2. 选择服务商，粘贴 API Key（只保存在本机）。修改会自动保存。
3. 点「测试连接」。结果分三档：可用 / 勉强可用 / 不可用，并给出中文原因和「详情」。【图 22、23、24】
4. 测试通过后会提示「现在切换到真实模型吗？」，点「切换并保存」即可。

## 5b. 费用与预算【图 41、42】
- 每次运行都会记录 tokens（服务商返回真实用量时用真实值，否则按字数估算），工具栏显示这个作品的累计（如“41k tokens · ¥0.12”），历史里每个版本也有本次用量。
- 点开始之前，操作栏主按钮左边显示**预估**（如“约 23k tokens · ¥0.10”）。演示模式显示“演示免费”。
- 「设置 → 费用与预算」：价目表已预置 DeepSeek、通义千问、Kimi、智谱、豆包、混元、OpenAI、Claude、Gemini 等常见模型（元 / 百万 tokens，按模型名前缀匹配，可改）；本地模型可设为 0。
- 可设**单次运行上限**和**每个作品上限**。预计超出时不会运行，并说明原因（如“预计本次费用 ¥0.10，超过单次预算 ¥0.05。可以先选中一部分只改那里…”）。

## 6. 出问题了怎么办
| 你看到的 | 意思 | 怎么做 |
|---|---|---|
| 红色条「这次 AI 没有按要求返回内容，已保留原样」【图 21】 | 模型返回了无法使用的内容，作品没有被改动 | 点底部操作栏的「重试 →」，或红色条上的「换个模型」；「查看原始回复」可以看模型到底说了什么 |
| 黄色条「已使用通用流程」【图 25】 | 模型没能规划出专门的步骤 | 可以直接开始，或换模型后「重新规划」 |
| 「API Key 无效或没有权限」 | Key 填错或没开通 | 检查是否复制完整、是否与服务商匹配 |
| 「无法连接到 xxx」 | 网络、代理或地址问题 | 检查网络和地址 |
| 「超过 60 秒没有响应」 | 服务繁忙或模型太慢 | 稍后重试或换模型 |
| 「已超出预算，没有运行」 | 预计费用超过你设的上限 | 先选中一部分只改那里，或在「设置 → 费用与预算」调高上限 |
| 「检查失败：连不上更新地址」 | 更新地址填错或网络不通 | 检查地址；不影响正常使用 |

运行中随时按 Esc 或点「停止」取消。

## 7. 导出
「导出」菜单支持：复制到剪贴板、Word（.docx）、Markdown、OPML（可导入 XMind 等脑图软件）、图片 PNG、JSON 等。【图 09】

## 8. 存为模板
觉得某个流程好用，点「存为模板」，填名称和说明。保存的是**流程**（步骤），不包含当前内容；下次从「模板库」直接开始。【图 08、14】

## 9. 专家模式

## 11. 数据
重新打开应用会直接回到上次的作品（顶部提示可「回到首页」）。
所有项目和设置都保存在本机，「设置 → 数据」可以打开数据文件夹。删除项目或作品后，提示条里可以「撤销」。

**自动备份**：每天第一次打开时自动备份全部作品；删除项目、恢复备份之前也会先备份。默认保留最近 10 份（「设置 → 备份与安全」可改）。列表里每份备份都有「恢复到这里」——恢复前会再给当前数据做一份“恢复前”备份，所以恢复本身也能撤回。

**API Key 加密**：Key 用系统加密保存（Windows 为 DPAPI，只有当前 Windows 用户能解密）。旧版本明文保存的 Key 在第一次打开新版本时自动加密。设置页会显示当前是否已加密。

**界面大小**：Ctrl+= 放大、Ctrl+- 缩小、Ctrl+0 还原；也可以在「设置 → 使用习惯」里选。

## 12. 检查更新与发布更新
- 「设置 → 更新」填更新地址后点「检查更新」：有新版本会自动下载，下载好后点「重启并安装」。地址不可达只会提示“连不上更新地址”，不影响使用。
- **怎么发布更新（给管理员）**：用 `npx electron-builder --win --x64` 打包后，`release/` 里会生成 `latest.yml`、`JianJin-Refiner-<版本>-Setup.exe` 和 `.blockmap`。把这三个文件原样上传到**任意静态文件服务器**的同一个目录（Nginx/IIS 目录、对象存储如 OSS/COS/S3 的公开桶、GitHub Pages、内网共享的 HTTP 服务都可以），然后把该目录的网址（如 `https://files.example.com/jianjin-refiner/`）填到用户的「更新地址」。每次发版只需提高 `package.json` 的 version 并覆盖上传这三个文件。
- 自动安装依赖 NSIS 安装版；便携版（Portable）与 zip 版只能提示有新版本，需要手动替换。


## 14. v1.7 新增
- **粗细色点与就绪度**：每个部分前的色点表示 粗（橙）/ 中（黄）/ 细（绿），悬停看原因；标题旁“就绪 N%”。底部“还有 N 处比较粗”，点“接着细化最粗的 3 处”一次补完。
- **往下展开全部**：第 2 步起主按钮逐个处理所有部分；想跳过这一步，在“更多”里。
- **只改一处**：单击选中某部分（双击或 F2 编辑文字），再运行，AI 只改这一部分，不会动别处。
- **金额**：说明里写了“约 4,500 元”会自动填进金额栏（标“推断”，手改后取消）；表格底部显示合计与预算余额，超预算标红。
- **导入乱草稿**：Word 表格会变成条目；“待定 / TODO / ？”会汇总到“待澄清的问题”。
- **AI 想先确认**：步骤之间如果 AI 发现缺少关键事实，会弹出问题卡；回答后成为固定事实（资料面板可查看/删除）。
- **完成卡**：交接清单（还没定的、缺字段、下一步行动），可导出 CSV 待办或 ICS 日历；“以此为基础新建”把概念拆成功能清单、任务或执行计划，新作品顶部有“来自：…”可跳回上游。


## 13. v1.7 新增
- **颜色点 = 成熟度**：橙=粗、黄=中、绿=细，悬停看原因；标题旁“就绪 N%”。底部提示条列出最粗的几处，点「接着细化最粗的 3 处」一次处理。
- **单击选中，双击或 F2 编辑**。选中后右侧检查器显示“选中：「…」”，此时 AI 只改这一部分，不会动其他部分。
- **往下展开全部**：第 2 步起主按钮逐个处理所有部分；跳过这一步在「更多」里。
- **金额**：说明里写的“约 4,500 元”会自动填进金额列（标“推断”，手改后取消）；表格底部显示合计与预算余量，分组显示小计，超出预算标红。
- **固定事实**：开头小问题的回答、以及 AI 中途“想先确认”的回答都会记在 资料 → 固定事实，之后每一步都遵守。
- **导入**：Word 表格变条目；“待定/TODO/?”收进“待澄清的问题”。
- **完成后**：交接清单列出还没定的、缺负责人的和下一步行动，可导出 CSV / ICS；「以此为基础新建」把概念拆成功能清单、任务或执行计划，新作品顶部“来自：…”可跳回，上游改了会提示。
- **修订变差会自动保留原版本**，并在说明中注明。


## 14. v1.8–v2.0 新增
- **每处改动下方有理由**（为什么改）；可逐条保留或撤回。
- **Ctrl+单击多选**几处，一次处理；检查器与内容并排。
- **首次打开作品**会看到 3 条就地提示（可“不再提示”）。
- **多处一起改会并行**（设置里可调同时处理几处）；运行中显示“并行 N 路 · 已完成 k/M”。
- **粒度**：选中一项后，检查器里「更粗 / 更细」只调这一项的粗细。
- **撤回会学习**：撤回的改动记进「资料 → 你的偏好」，之后 AI 会避开；可停用或删除。
- **导出**：新增「白板 JSON Canvas」（Obsidian 等）和「Mermaid 图」（有日期→甘特，否则脑图）。


## 15. v2.1–v2.3 新增
- **改动清单（侧栏）**：待审阅时右侧列出新增 / 修改 / 删除，带改前改后与理由，可保留、撤回、点击跳转。
- **逐处确认**：设置里打开「多处细化时逐处确认」后，多处一起改时每改完一处会停下来，可保留、撤回、其余不再询问，或先停在这里。默认关闭。
- **偏好作用域**：资料面板里的偏好可设为「仅本作品」或「所有作品」，并可导出 / 导入 JSON。
- **多视角备忘**：第一次铺整体前，执行者 / 审查者 / 使用者会先各写一段短备忘（设置里可关；失败不影响主流程）。作品上会显示「多视角备忘」卡。
- **导出**：新增「网页 HTML」（离线打开、打印）、「Markdown 表格」、以及「交接包」zip（内含 HTML、表格、JSON Canvas 白板、Mermaid 图和说明）。不需要任何在线账号。
